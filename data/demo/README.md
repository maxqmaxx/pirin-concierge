# Synthetic demo catalogue

This directory contains exactly 12 fictional experience records used to validate the Pirin Concierge
TRL 4 laboratory demonstrator. Bansko, Razlog, Banya and Dobarsko are real settlement names; every
experience, host identity, price and availability statement is invented for software testing.

The records:

- are explicitly marked `synthetic: true`;
- use synthetic host identifiers and contain no host or visitor contact details;
- do not represent an operating business, a real offer or verified availability;
- support booking **requests only**: a host would have to confirm separately and take payment directly;
- must never be presented as evidence that a named local person or business offers an activity.

There are three records for each settlement. Prices are interface fixtures in EUR, not market evidence.
The file is safe to publish as demo data, but it must not be merged with real host data or survey
microdata. See the repository `NOTICE.md` for the applicable data licence and attribution terms.
